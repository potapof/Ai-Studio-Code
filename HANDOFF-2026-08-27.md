### 2. Корень «вечного 429» в E2E (важно для будущих прогонов)
E2E-контейнер backend (--network host) не мог занять :3000 — EADDRINUSE: порт держал
ЛОКАЛЬНЫЙ dev-backend Студии. E2E-тесты ходили в локальный backend (дефолтные лимиты) →
429. Симптом в логе контейнера: «Error: listen EADDRINUSE ... 0.0.0.0:3000», при этом
docker run -d «успешен», а Wait for backend проходит (curl отвечает от чужого процесса).
Лечение: `fuser -k 3000/tcp` + `docker rm -f backend` перед rerun E2E → контейнер занял
порт, E2E зелёная. РЕКОМЕНДАЦИЯ: добавить в ci.yml E2E Start backend шаг освобождения
порта (`fuser -k 3000/tcp 2>/dev/null || true`) — иначе self-hosted CI конфликтует с dev.
