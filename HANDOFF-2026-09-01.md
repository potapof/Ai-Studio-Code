## ГРАБЛИ / НЮАНСЫ (важно!)
- **pnpm PATH**: pnpm в `~/.npm-global/bin/pnpm`; иногда нужно `export PATH="$HOME/.npm-global/bin:$PATH"` (иначе «command not found»; при параллельных terminal-вызовах PATH может сбрасываться).
- **Bearer-маскировка**: при правке `Authorization` в api.ts вывод маскирует `Bearer`→`***` (это НЕ порча файла — проверять через `grep -c 'Bearer'`). Один раз патч-инструмент реально записал `*** ` вместо `Bearer` (сломал шаблонную строку) — исправлял через python. В НОВОМ коде лучше вызывать `http()` БЕЗ явного `headers: { Authorization }` (http() сам подставляет токен).
- **Toast API**: `toast({ type: 'success'|'error'|'warning'|'info', title, message })` — обязательно `type` (не `title`+`description`).
- **Хвостовик списка товаров кэшируется** (buildListCacheKey) — обновление inventory видно не сразу; создание через сервис инвалидирует кэш.
- git-дерево держать чистым; коммитить в develop (не в main).
